📖 Systemintegration – Fachglossar

In diesem Glossar werden wichtige Fachbegriffe aus der Systemintegration und modernen IT-Infrastrukturen erklärt. Die Zusammenstellung dient als Übersicht für mein Selbststudium und zur Vertiefung meiner IT-Kenntnisse.

Active Directory (AD)

Active Directory ist ein Verzeichnisdienst von Microsoft, der in Windows-Server-Umgebungen eingesetzt wird. Administratoren können damit Benutzer, Computer, Gruppen und Berechtigungen zentral verwalten. Über Gruppenrichtlinien (Group Policy) lassen sich außerdem Einstellungen und Sicherheitsvorgaben für Benutzer und Computer festlegen.

DNS (Domain Name System)

DNS übersetzt Domainnamen wie beispielsweise www.example.com in IP-Adressen. Dadurch müssen Benutzer keine numerischen IP-Adressen kennen, um Webseiten und andere Netzwerkdienste aufzurufen. DNS ist ein grundlegender Bestandteil moderner Netzwerke.

DHCP (Dynamic Host Configuration Protocol)

DHCP ermöglicht die automatische Vergabe von Netzwerkeinstellungen an Geräte. Dazu gehören beispielsweise IP-Adresse, Subnetzmaske, Standardgateway und DNS-Server. Dadurch müssen diese Einstellungen nicht auf jedem Gerät manuell vorgenommen werden.

Virtualisierung (Hyper-V / Proxmox)

Bei der Virtualisierung werden die Ressourcen eines physischen Computers oder Servers auf mehrere virtuelle Maschinen (VMs) aufgeteilt. Jede virtuelle Maschine kann ein eigenes Betriebssystem und eigene Anwendungen ausführen. Hyper-V von Microsoft und Proxmox VE sind Beispiele für Virtualisierungsplattformen.

RAID-Systeme (Redundant Array of Independent Disks)

RAID bezeichnet den Zusammenschluss mehrerer Festplatten oder SSDs zu einem logischen Speichersystem. Je nach RAID-Level stehen unterschiedliche Eigenschaften im Vordergrund:

RAID 0: Daten werden auf mehrere Laufwerke verteilt. Das kann die Leistung erhöhen, bietet aber keine Ausfallsicherheit. Fällt ein Laufwerk aus, können alle Daten des Verbunds verloren gehen.

RAID 1: Daten werden auf mindestens zwei Laufwerken gespiegelt. Fällt ein Laufwerk aus, sind die Daten normalerweise weiterhin auf dem anderen Laufwerk verfügbar.

RAID 5: Daten und Paritätsinformationen werden auf mindestens drei Laufwerken verteilt. Der Ausfall eines Laufwerks kann ausgeglichen werden.

RAID ersetzt keine regelmäßige Datensicherung.

3-2-1-Backup-Regel

Die 3-2-1-Regel ist ein bewährtes Konzept zur Datensicherung. Sie empfiehlt:

3 Kopien: Mindestens drei Versionen der Daten sollten vorhanden sein – das Original und zwei Sicherungskopien.

2 Medien: Die Kopien sollten auf mindestens zwei unterschiedlichen Speichermedien oder Speichersystemen liegen.

1 externer Speicherort: Mindestens eine Kopie sollte räumlich getrennt aufbewahrt werden, beispielsweise in einem anderen Gebäude oder in einem geeigneten Cloud-Speicher.

Firewall

Eine Firewall überwacht und kontrolliert den ein- und ausgehenden Netzwerkverkehr anhand festgelegter Regeln. Sie kann beispielsweise bestimmte Verbindungen erlauben oder blockieren und so dazu beitragen, Netzwerke und Systeme vor unerwünschten Zugriffen zu schützen.

VPN (Virtual Private Network)

Ein VPN ermöglicht den Aufbau einer geschützten Verbindung über ein öffentliches oder fremdes Netzwerk. Unternehmen verwenden VPN-Verbindungen beispielsweise, damit Mitarbeiter von außerhalb sicher auf interne Systeme und Ressourcen zugreifen können.

TCP und UDP

TCP und UDP sind Transportprotokolle, die Daten zwischen Anwendungen über Netzwerke übertragen.

TCP: Bietet eine zuverlässige, verbindungsorientierte Übertragung. Die korrekte Reihenfolge und der Empfang der Daten werden überwacht.

UDP: Überträgt Daten ohne vorherigen Verbindungsaufbau. Es hat weniger Verwaltungsaufwand und wird beispielsweise bei DNS-Anfragen und Echtzeitanwendungen eingesetzt.

IP-Adresse

Eine IP-Adresse identifiziert ein Gerät beziehungsweise eine Netzwerkschnittstelle innerhalb eines IP-Netzwerks. Man unterscheidet unter anderem zwischen IPv4 und IPv6. IPv4-Adressen bestehen aus vier Zahlenblöcken, während IPv6 einen deutlich größeren Adressraum bietet.

Subnetzmaske

Eine Subnetzmaske legt bei IPv4 fest, welcher Teil einer IP-Adresse zum Netzwerk und welcher Teil zum jeweiligen Gerät gehört. Sie hilft dabei, Netzwerke in kleinere Teilnetze aufzuteilen und die Adressvergabe zu strukturieren.

Standardgateway

Das Standardgateway ist normalerweise ein Router, über den ein Gerät Daten an andere Netzwerke weiterleitet, wenn das Ziel nicht im eigenen lokalen Netzwerk liegt. In Heimnetzwerken übernimmt häufig der Router diese Aufgabe.

NAS (Network Attached Storage)

Ein NAS ist ein Speichergerät, das über das Netzwerk erreichbar ist. Es kann beispielsweise zur zentralen Speicherung von Dateien, zur gemeinsamen Nutzung von Dokumenten und für Datensicherungen eingesetzt werden.

Proxmox VE

Proxmox Virtual Environment ist eine Open-Source-Plattform zur Verwaltung von virtuellen Maschinen und Linux-Containern. Sie bietet eine webbasierte Verwaltungsoberfläche und wird häufig für Homelabs und Serverumgebungen eingesetzt.
