🌐 Protokoll-Labor: Infrastruktur-Grundlagen

Erarbeitung der essenziellen Netzwerkdienste im Selbststudium zur Vorbereitung auf die Ausbildung im Bereich Systemintegration.

1. DHCP (Dynamic Host Configuration Protocol)

Automatisierte Zuweisung von Netzwerkkonfigurationen an Geräte innerhalb eines IP-Netzwerks.

  • Zuweisung von: IP-Adresse, Subnetzmaske, Standard-Gateway und DNS-Servern.
  • Praxis-Architektur: Realisierbar über eigenständige Server (z. B. Linux-Dienste oder Windows Server) oder standardmäßig integrierte Funktionen in Routing-Endgeräten im Heimnetzwerk.
  • DHCP-Ablauf: Discover, Offer, Request und Acknowledge (DORA).

2. DNS (Domain Name System)

Hierarchisches Namenssystem zur Übersetzung von Domainnamen in IP-Adressen und zur Bereitstellung weiterer Informationen über Netzwerkdienste.

  • A-Record: Auflösung eines Domainnamens in eine IPv4-Adresse.
  • AAAA-Record: Auflösung eines Domainnamens in eine IPv6-Adresse.
  • CNAME-Record: Alias-Verweis eines Domainnamens auf einen anderen kanonischen Domainnamen.
  • MX-Record: Legt fest, welche Mailserver für den Empfang von E-Mails einer Domain zuständig sind.
  • TTL (Time to Live): Gibt an, wie lange ein DNS-Eintrag zwischengespeichert werden darf.

3. Gateway & NAT

Das Standard-Gateway stellt die Verbindung zwischen dem lokalen Netzwerk (LAN) und anderen Netzwerken, beispielsweise dem Internet (WAN), her.

  • Routing: Datenpakete an netzwerkfremde IP-Adressen werden an das Standard-Gateway weitergeleitet.
  • NAT (Network Address Translation): Übersetzt IP-Adressen zwischen verschiedenen Netzwerkbereichen.
  • PAT (Port Address Translation): Ermöglicht mehreren Geräten im privaten Netzwerk, eine gemeinsame öffentliche IP-Adresse zu nutzen, indem zusätzlich Portnummern zur Unterscheidung verwendet werden.

4. ARP (Address Resolution Protocol)

ARP wird innerhalb lokaler IPv4-Netzwerke verwendet, um zu einer bekannten IPv4-Adresse die passende MAC-Adresse eines Geräts zu ermitteln.

  • ARP Request: Ein Gerät fragt im lokalen Netzwerk nach der MAC-Adresse zu einer bestimmten IPv4-Adresse.
  • ARP Reply: Das gesuchte Gerät antwortet mit seiner MAC-Adresse.
  • ARP-Cache: Bereits ermittelte Zuordnungen werden vorübergehend gespeichert.

5. TCP & UDP

TCP und UDP sind wichtige Transportprotokolle, die für die Übertragung von Daten zwischen Anwendungen in Netzwerken verwendet werden.

  • TCP (Transmission Control Protocol): Verbindungsorientiertes Protokoll mit zuverlässiger und geordneter Datenübertragung.
  • UDP (User Datagram Protocol): Verbindungsloses Protokoll mit geringem Verwaltungsaufwand. Eine Zustellung oder Reihenfolge der Datenpakete wird nicht garantiert.
